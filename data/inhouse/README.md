# In-house DFT datasets

30 extxyz files with per-atom `initial_magmoms` (muB), `DFT_force` and `MACE_force` (eV/A).
Inventory: `manifest.csv`.  Documentation and population registry: `../../docs/DATASETS.md`,
`../../magnetic_ambiguity/inhouse.py`.  Verify: `sha256sum -c checksums.sha256`.
Source data are immutable; never edit these files.
